# DJI-HDMI Bluetooth

Page de réglage par Bluetooth des boîtiers DJI-HDMI (Raspberry Pi qui affiche
la vidéo des DJI Goggles 3 en HDMI).

**Ouvrir la page : https://tellus75.github.io/dji-hdmi-bluetooth/**

- Android, PC, Mac : Chrome ou Edge. iPhone / iPad : application Bluefy.
- Mot de passe : celui du Wi-Fi du boîtier (affiché sur son écran d'attente).
- Après une première ouverture, la page fonctionne aussi sans Internet.

Page statique, sans serveur : tout se passe entre le navigateur et le boîtier
(Web Bluetooth). Le Bluetooth se coupe et les téléphones appairés s'oublient
depuis la page de réglages du boîtier (onglet Réseau).
